# CulqiAngular

Culqi implementation example in Angular using the [ngx-culqi](https://github.com/lperezp/ngx-culqi) library. v3.0.0

> **Note:** To quickly test the library, there's a form to enter the API key. These values ​​aren't stored anywhere. Feel free to change it by creating a local .env file.
